This directory contains the following programmatically generated files:

- `bls12_381/arc_t3.bin`, the round constants for the ARC layer of Poseidon(T=3) over the BLS12-381
  scalar field
- `bls12_381/arc_t4.bin`, the round constants for the ARC layer of Poseidon(T=4) over the BLS12-381
  scalar field
- `bls12_381/fl_t3.bin`, the matrix for the full linear layer of Poseidon(T=3) over the BLS12-381
  scalar field
- `bls12_381/fl_t4.bin`, the matrix for the full linear layer of Poseidon(T=4) over the BLS12-381
  scalar field
- `bls12_381/pl_t3.bin`, the matrix for the partial linear layer of Poseidon(T=3) over the BLS12-381
  scalar field
- `bls12_381/pl_t4.bin`, the matrix for the partial linear layer of Poseidon(T=4) over the BLS12-381
  scalar field
- `bluesky/arc_t3.bin`, the round constants for the ARC layer of Poseidon(T=3) over the BlueSky
  scalar field
- `bluesky/arc_t4.bin`, the round constants for the ARC layer of Poseidon(T=4) over the BlueSky
  scalar field
- `bluesky/fl_t3.bin`, the matrix for the full linear layer of Poseidon(T=3) over the BlueSky scalar
  field
- `bluesky/fl_t4.bin`, the matrix for the full linear layer of Poseidon(T=4) over the BlueSky scalar
  field
- `bluesky/pl_t3.bin`, the matrix for the partial linear layer of Poseidon(T=3) over the BlueSky
  scalar field
- `bluesky/pl_t4.bin`, the matrix for the partial linear layer of Poseidon(T=4) over the BlueSky
  scalar field

All files have been generated by manually adapting the [official Rust code][poseidon2-params] for
BLS12-381 and BlueSky.

[poseidon2-params]: https://github.com/HorizenLabs/poseidon2/blob/main/plain_implementations/src/poseidon2/poseidon2_params.rs
